# 🎤 说话人识别功能文档

## 功能概述

Rose Voice 录音转写系统现已支持说话人识别功能！通过集成火山引擎的 `with_speaker_info` 参数，系统可以自动识别并区分音频中的不同说话人。

## ✨ 新增功能

### 1. 自动说话人检测
- 🎯 自动检测音频中的说话人数量
- 👥 支持多人对话场景
- 🔄 实时说话人切换识别

### 2. 详细统计信息
- ⏱️ 每位说话人的发言时长
- 📊 发言片段数量统计
- 📝 发言文字数量统计
- 🕐 首次和最后出现时间

### 3. 对话流程展示
- 🎭 按时间顺序显示对话流程
- 🏷️ 清晰标识每个说话人
- ⏰ 精确的时间戳信息

## 🔧 技术实现

### 火山引擎ASR配置

```javascript
{
  request: {
    model_name: 'bigmodel',
    enable_speaker_info: true,     // 启用说话人信息
    enable_punc: true,
    enable_itn: true,
    show_utterances: true,
    with_speaker_info: true,       // 🎯 新增：启用说话人识别
    speaker_number: 'auto'         // 🎯 新增：自动检测说话人数量
  }
}
```

### 数据库结构更新

新增字段：
- `speaker_count` (INTEGER): 说话人数量
- `speaker_info` (TEXT): 说话人详细信息(JSON格式)

### 数据结构示例

```javascript
// 说话人信息结构
{
  speaker_count: 3,
  speakers: [
    {
      id: '1',
      total_duration: 15000,    // 毫秒
      segment_count: 5,
      words_count: 120,
      first_appear: 0,
      last_appear: 30000
    },
    // ... 更多说话人
  ],
  segments: [
    {
      index: 0,
      speaker: '1',
      start_time: 0,
      end_time: 3500,
      duration: 3500,
      text: '大家好，欢迎参加今天的会议。',
      text_length: 16
    },
    // ... 更多片段
  ],
  summary: '检测到3个说话人，主要说话人: 1 (45%时长)',
  analysis: {
    total_segments: 8,
    speakers_detected: 3,
    main_speaker: '1'
  }
}
```

## 📋 使用指南

### 1. 录音上传
正常上传音频文件，系统会自动启用说话人识别功能。

### 2. 等待处理
系统会：
1. 上传音频到云端存储
2. 提交ASR任务（启用说话人识别）
3. 自动轮询处理结果
4. 解析并存储说话人信息

### 3. 查看结果
- 在录音列表中查看说话人数量预览
- 点击录音项目查看详细说话人分析
- 导出包含说话人信息的完整转录结果

## 🐛 故障排除

### 常见问题

1. **说话人识别失败**
   - 检查音频质量
   - 确认环境变量配置
   - 查看ASR响应日志

2. **说话人数量不准确**
   - 音频中说话人声音相似
   - 背景噪音干扰
   - 音频时长过短

3. **显示异常**
   - 检查浏览器控制台错误
   - 确认数据库字段完整性
   - 验证JSON数据格式

### 调试工具

- 查看 `debug/asr_response_debug.json` 文件
- 检查数据库中的 `speaker_info` 字段
- 运行测试脚本验证功能
