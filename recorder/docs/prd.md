# PRD：VolcVoice 录音转写 Web 应用  
**版本**：v1.0  
**作者**：Product Team  
**日期**：2024-07-20  

---

## 1. 背景与目标
| 项目 | 说明 |
|---|---|
| **背景** | 用户需要快速将本地录音转为文字并长期留存，当前缺乏一站式、低成本、易迁移的 SaaS 工具。 |
| **目标** | 上线一款 Web App，支持 **上传录音→自动转写→查看/播放历史**，30 分钟内可完成部署。 |
| **KPI** | 1. 7 天内上线 MVP；2. 首月转写成功率 ≥ 98 %；3. 后续 1 人日即可迁移到小程序。 |

---

## 2. 产品范围
### 2.1 功能清单
| 模块 | 功能点 | 优先级 |
|---|---|---|
| 录音上传 | 浏览器选择文件（mp3/wav/m4a） | P0 |
| 云端转写 | 自动触发火山引擎 ASR，支持说话人分离 | P0 |
| 结果展示 | 文字 + 音频播放器 | P0 |
| 历史列表 | 分页、搜索（关键词高亮） | P1 |
| 下载导出 | 文字 TXT / 音频原文件 | P1 |
| 小程序迁移 | 仅替换上传 SDK，零后端改动 | 后续 |

### 2.2 非功能需求
- **并发**：单地域 100 QPS，可横向扩展。  
- **延迟**：转写完成 ≤ 3 min（5 min 音频）。  
- **成本**：首月 ≤ 50 元（利用火山免费额度）。  
- **兼容性**：Chrome ≥ 90, Edge ≥ 90, Safari ≥ 14。  

---

## 3. 用户故事
| 角色 | 故事 | 验收标准 |
|---|---|---|
| 律师 | 上传庭审录音，查看转写并导出 | 转写准确率 ≥ 95 %，可下载 TXT |
| 学生 | 上传课堂录音，搜索关键词 | 搜索响应 < 500 ms，关键词高亮 |
